Discord image posting limitations

  • Files with message JSON must be sent as multipart/form-data; the JSON body belongs in payload_json, and files use unique files[n] parts.
  • The Create Message endpoint has a maximum request size of 25 MiB. Keep the generated PNG comfortably below that.
  • Discord's file upload limit is enforced per file. The developer docs list a default of 10 MiB, with higher limits possible from Nitro or server boost status; interaction payloads can expose attachment_size_limit.
  • Normal image attachments can display differently across Discord clients because chat previews are scaled to the available message column. The PNG should be readable after client scaling, not only at native 1280px width.
  • When content includes the Warcraft Logs URL, use SUPPRESS_EMBEDS so Discord does not add a separate link preview under the PNG.
  • For embed attachment images, Discord documents attachment://filename.png and supports .jpg, .jpeg, .png, .webp, and .gif. This project is using a normal PNG attachment instead.

Sources: Discord Uploading Files, Discord Create Message.
